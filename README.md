# Machine Learning Zoomcamp — Homework

This repository contains my homework, assignments, notes, and practice work from the **Machine Learning Zoomcamp by DataTalksClub**.

The goal of this repository is to document my learning journey through the course and build a strong foundation in machine learning, from basic concepts to model deployment.

## 📚 About the Course

**Machine Learning Zoomcamp** is a practical machine learning course by [DataTalksClub](https://datatalks.club/).

The course covers the complete machine learning workflow, including:

* Python for Machine Learning
* NumPy and Pandas
* Exploratory Data Analysis
* Linear Regression
* Logistic Regression
* Classification
* Decision Trees
* Ensemble Methods
* Machine Learning Evaluation
* Deployment
* Docker
* Cloud and Kubernetes
* End-to-end Machine Learning projects
